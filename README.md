# EduMate - Smart Student Assistant Robot

## Overview

EduMate is an Arduino Uno based Smart Student Assistant Robot designed to improve student productivity through reminders, timers, temperature monitoring, and an interactive LCD interface.

---

## Features

- Animated LCD Eyes
- Menu Driven Interface
- LM35 Temperature Sensor
- Timer
- Stopwatch
- Homework Reminder
- Water Reminder
- Stretch Reminder
- Sleep Reminder
- Motivational Quotes
- Greeting Messages
- Silent/Beep Mode
- Flashlight LED

---

## Components

- Arduino Uno
- 16x2 I2C LCD
- LM35 Temperature Sensor
- Push Buttons
- Buzzer
- LEDs
- Breadboard
- Jumper Wires
